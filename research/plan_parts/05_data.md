Без пунктов 5–6 модель всё равно обучаемая, но целевая метка определяется по косвенным статусам («Неисправен», «Обесточен», «Затоплен»), а не по журналу ремонтов. Фиксируем это допущение явно.

### Допущения по целевой переменной (ground truth)

1. **«Отказ датчика в ближайшие 24 ч»** = появление у канала статусов «Неисправен»/«Обесточен»/«Отключено устройство» в окне +24 ч. ✱ кампании исключены.
2. **«Пожарный риск»** = тревога дыма/газа/тепла в окне +24 ч, исключая кампании проверок.
3. **«Несанкционированный доступ»** = тревога движения/КД в нерабочее время без корректного допуска (данные АРМ-Контроль).
4. **«Износ»** = рост частоты неисправностей/отказов насоса/вентилятора + возраст + погода (модель второго порядка).

### Уточнения экспертов (16.09) к допущениям
- Отказ — цепочка «датчик→шина→питание→контроллер→модем→канал→сервер»; «неисправность» канала — прокси, допустимый для обучения.
- Для **бинарных** датчиков цель событийная (серия/первая тревога); для **цифровых** (температура, газ) — тренды значений и превышения порогов.
- Доступ: положительная эвристика — **последовательность** (дверь/люк + объёмный + движение соседней зоны); одиночный сигнал — не положительный.
- Пожар: подтверждённой метки нет → «риск-скоре» с объяснением (температура >100° ≠ пожар).
